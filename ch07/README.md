# 第7章　リランクで、正しい文書を上位に並べる

本の第7章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch07/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で使ったファイルもすべて入っています。

この章では、Dify のナレッジの検索設定でリランクのモデル（jina-reranker-m0）を選びます。設定は Dify の画面で行うので、サンプルコードのファイルは変わりません。第6章と同じように、`STATUS` を「有効」にして `evaluate.py` で測り直します。

## うまくいったかの確かめ方

- `STATUS` を「有効」にして測ると、1位の数が第6章より多い

動作しないときは、本の第7章の「うまくいかないとき」を見てください。

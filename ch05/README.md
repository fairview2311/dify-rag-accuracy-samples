# 第5章　日本語の全文検索とハイブリッド検索で外れを減らす

本の第5章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch05/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で使ったファイルもすべて入っています。

この章では、Dify の `.env` の2行を書き換えて、日本語の全文検索とハイブリッド検索のナレッジを作り直します。書き換えるのは自分の `dify/docker/.env` なので、サンプルコードのファイルは変わりません。新しいナレッジの ID を `DIFY_DATASET_ID` に設定し直して同期し、第4章の `evaluate.py` で点数を測り直します。毎朝の自動実行を登録したときは、`run_sync.ps1`（Mac は `run_sync.sh`）のナレッジの ID も書き換えます。環境変数を保存しているときは、書き換えた後に、トップの README の「毎回の入力を省く（おすすめ）」のコマンドをもう一度実行します。

## うまくいったかの確かめ方

- `evaluate.py` の点数が、第4章より上がる（数は本の第5章）

動作しないときは、本の第5章の「うまくいかないとき」を見てください。

第4章から変更したファイルはありません。

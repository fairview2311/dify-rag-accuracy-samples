# 第10章　経費・出張の申請を、規程と照らし合わせる

本の第10章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch10/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- 出張と経費の申請の Excel を、規程と照らし合わせて確かめる Web アプリがある

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーに `dify-rag-accuracy-samples-main` として展開し、作業用のフォルダー（`sp_sync`・`evaluate`・`report`）もホームのフォルダーに作ってある前提です（[リポジトリのトップ](../README.md)の「フォルダーの置き場所」）。環境変数は、トップの README の「毎回の入力を省く（おすすめ）」のとおりに保存しておくと、PowerShell やターミナルを開き直すたびに設定し直す必要がありません。

1. このフォルダーの `expense_check.yml` を、テキストエディターで開きます。「ナレッジの ID」の1か所を、「社内規程と手順書（日本語検索）」の ID に書き換えて、UTF-8 のまま上書き保存します。

2. Dify の「スタジオ」の［作成］→［アプリをインポート］で `expense_check.yml` を読み込み、公開します。OpenAI と Jina のプラグインを使います。

3. 公開したアプリを［Web アプリを開く］で開き、サンプルコードの `data/申請/出張と経費の申請_2026年10月.xlsx` を添付して実行します。

## うまくいったかの確かめ方

- 編集の画面で、「規程を探す」の下に「社内規程と手順書（日本語検索）」と表示される（本の図10-4）
- 7行の申請のうち、規程に合わない行と、その根拠の規程が表示される

動作しないときは、本の第10章の「うまくいかないとき」を見てください。

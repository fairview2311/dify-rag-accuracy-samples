# 第8章　社員の規程の質問に、出典付きで答える

本の第8章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch08/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- 社員の規程の質問に、出典付きで答える Dify のアプリ（チャットフロー）がある
- 答えが規程に無い質問は、Teams の総務部のチャネルに送られる
- 30 問をアプリに聞いて、答えを CSV に書き出せる

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーに `dify-rag-accuracy-samples-main` として展開し、作業用のフォルダー（`sp_sync`・`evaluate`・`report`）もホームのフォルダーに作ってある前提です（[リポジトリのトップ](../README.md)の「フォルダーの置き場所」）。環境変数は、トップの README の「毎回の入力を省く（おすすめ）」のとおりに保存しておくと、PowerShell やターミナルを開き直すたびに設定し直す必要がありません。

1. このフォルダーの `sp_sync.py` を、ホームの `sp_sync` フォルダーにコピーして上書きし、同期し直します。文書の「出典」もメタデータに書き込まれます。

2. このフォルダーの `policy_qa.yml`（チャットフローの DSL）を、テキストエディターで開きます。「ナレッジの ID」「チームの ID」「チャネルの ID」の3か所を自分の値に書き換え、UTF-8 のまま上書き保存します。チャネルの ID は、値の前後を `'` で囲みます。値の調べ方は、本の第8章の「DSL ファイルに ID を書き込む」にあります。

3. Dify の「スタジオ」の［作成］→［アプリをインポート］で `policy_qa.yml` を読み込みます（本の図8-4・図8-5）。編集の画面の右上の［公開する］を押して公開します（本の図8-11）。

4. このフォルダーの `ask.py` を、ホームの `evaluate` フォルダーにコピーします。アプリの API キー（`app-` で始まる）を `DIFY_APP_KEY` に設定して実行します。30 問を順に聞くので、2分ほどかかります。

   Windows（PowerShell）:

   ```text
   cd $HOME\evaluate
   $env:DIFY_APP_KEY = "app-で始まるキー"
   ..\sp_sync\.venv\Scripts\python.exe ask.py ..\dify-rag-accuracy-samples-main\data\質問集.csv 答え_第8章.csv
   ```

   Mac（ターミナル）:

   ```text
   cd ~/evaluate
   export DIFY_APP_KEY="app-で始まるキー"
   ../sp_sync/.venv/bin/python ask.py ../dify-rag-accuracy-samples-main/data/質問集.csv 答え_第8章.csv
   ```

## うまくいったかの確かめ方

- アプリの Web アプリで規程の質問をすると、出典の文書名とリンクの付いた答えが返る
- `evaluate` フォルダーに `答え_第8章.csv` ができ、答えの無い質問の分だけ Teams のチャネルに投稿が届く
- DSL ファイルは、ID を書き込んで上書きすると日本語の目印が消えます。もう一度使うときは、書き込む前のファイル（ch14 フォルダーのもの）を使います

動作しないときは、本の第8章の「うまくいかないとき」を見てください。

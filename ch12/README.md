# 第12章　新人・異動者の手順書とチェックリストを作る

本の第12章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch12/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- 新人・異動者の手順書とチェックリスト（Excel）を作り、上長への下書きのメールにできる

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーに `dify-rag-accuracy-samples-main` として展開し、作業用のフォルダー（`sp_sync`・`evaluate`・`report`）もホームのフォルダーに作ってある前提です（[リポジトリのトップ](../README.md)の「フォルダーの置き場所」）。環境変数は、トップの README の「毎回の入力を省く（おすすめ）」のとおりに保存しておくと、PowerShell やターミナルを開き直すたびに設定し直す必要がありません。

1. このフォルダーの `onboarding.yml` を、テキストエディターで開きます。「ナレッジの ID」の1か所を、「社内規程と手順書（日本語検索）」の ID に書き換えて上書き保存します。

2. Dify の「スタジオ」の［作成］→［アプリをインポート］で `onboarding.yml` を読み込み、公開します。OpenAI・Jina・Outlook・Markdownエクスポーターのプラグインを使います。

## うまくいったかの確かめ方

- 編集の画面で、「手順書を探す」の下にナレッジの名前が表示される
- Web アプリで実行すると、Outlook に手順書とチェックリストの付いた下書きができる

動作しないときは、本の第12章の「うまくいかないとき」を見てください。

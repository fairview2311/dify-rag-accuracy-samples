# 第9章　問い合わせメールに、返信の下書きを作る

本の第9章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch09/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- 総務部に届いた問い合わせメールに、規程に沿った返信の下書きを Outlook に作れる

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーに `dify-rag-accuracy-samples-main` として展開し、作業用のフォルダー（`sp_sync`・`evaluate`・`report`）もホームのフォルダーに作ってある前提です（[リポジトリのトップ](../README.md)の「フォルダーの置き場所」）。環境変数は、トップの README の「毎回の入力を省く（おすすめ）」のとおりに保存しておくと、PowerShell やターミナルを開き直すたびに設定し直す必要がありません。

1. このフォルダーの `mail_reply.yml` を、テキストエディターで開きます。「ナレッジの ID」の1か所を、第8章と同じナレッジの ID に書き換えて、UTF-8 のまま上書き保存します。

2. Dify の「スタジオ」の［作成］→［アプリをインポート］で `mail_reply.yml` を読み込みます。Outlook・OpenAI・Jina のプラグインを使います。インストールを求められたら、本の第2章・第7章のとおりにインストールします。

## うまくいったかの確かめ方

- 編集の画面で、「規程を探す」の下に「社内規程と手順書（日本語検索）」と表示される（本の図9-4）
- ワークフローを実行すると、Outlook の下書きのフォルダーに返信の下書きができる

動作しないときは、本の第9章の「うまくいかないとき」を見てください。
